# 决策规则速查 — The Comedy Writers Companion

| 能力 | 一句话规则 |
|---|---|
| Comic Skeleton — beat sequence that supports jokes | A comic skeleton is the beat sequence that supports jokes. |
| Comic Duo Structure | Two characters with opposing wants create a self-escalating engine. |
| Comic Ensemble / Multi-Perspective Group Dynamics | Ensemble distributes the comic engine across multiple characters, each with a unique filter on the same situation. |
| Joke-Driven Structure | Joke-driven structure uses comic escalation instead of plot causality. |
| Comic Escalation | Escalation is predictable variation on a comic rule. |
| Comic Character Engine | A comic engine is a character trait applied consistently. |
| Premise Variants (Fish-Out-of-Water etc.) | Different comic genres use different premise formulas. |

# Comic Skeleton
## R — Reading
Vorhaus treats structure as a *skeleton* — the beat structure that supports jokes. A comic skeleton is a sequence of escalation beats on a single comic rule. Unlike dramatic structure (causality), comic structure is about *variation*: each beat is a predictable variation on the comic rule, escalating until the payoff.
## I — Interpretation
The skeleton separates *what happens* from *what's funny*. Same event beats can carry different comic payloads — the skeleton is the delivery mechanism. Comic skeletons work because audiences track patterns; a predictable escalation pattern lets the audience anticipate, which is the setup for either payoff (satisfying) or subversion (surprising).
## A1 — Application
Use for shortform pieces where the comic premise is already established and you need the beat structure to deliver it. In 60s: skeleton = 5-8 beats: establish (5s) → escalate ×3-4 (35s) → payoff (15s) → optional coda (5s).
## A2 — Trigger signals
- "Structure this comedy piece"
- "This comedy has no spine"
- "How do I make this escalate?"
## E — Executable steps
1. Write the comic rule (one falsifiable sentence).
2. Choose 5-8 beats, each a variation on the rule (who/where/how varies).
3. Order beats from least to most extreme.
4. Position the payoff at the last beat — the variation that breaks the pattern.
5. Add a coda only if the callback lands cleanly.
## B — Boundary / common failures
- **Trap**: beats that aren't variations — new information or new settings instead of rule variations.
- **Trap**: escalation that goes in circles — each beat must be *more* extreme.
- **Not** for plot-driven comedy where the story itself is funny (different skeleton).

# Comic Duo Structure
## R — Reading
The duo is the primary comic geometry: two characters with opposing wants create a self-escalating engine. The classic duo has a **straight** (the normal/reasonable one) and a **comic** (the eccentric/committed one). But the engine is *goal opposition*, not role assignment — the straight's want blocks the comic's want, and vice versa.
## I — Interpretation
The duo works because each character is the other's opposition — the comedy is self-generating: no external villain needed. The straight/comic assignment can flip (the "straight" can be the funnier one when the situation reveals their absurdity).
## A1 — Application
For two-hander shortform: define each character's want in one sentence. The wants must collide at every beat. Don't write the straight as a killjoy — their reasonableness is the engine that keeps the comic honest.
## A2 — Trigger signals
- "Design a comic duo"
- "Two characters but no sparks"
- "Who should be the funny one?"
## E — Executable steps
1. Write each character's want in one sentence.
2. Check opposition: can each want exist without the other failing?
3. Assign initial straight/comic — but check if flip works.
4. Write 3 beats where the wants collide with escalation.
5. Decide who wins — the straight gets what they wanted, or the comic's absurdity is validated.
## B — Boundary / common failures
- **Trap**: straight as killjoy — their want must be as sympathetic as the comic's.
- **Trap**: duo without collision — two parallel tracks, not a dialogue.
- **Trap**: static roles — the engine dies if the straight never flips.

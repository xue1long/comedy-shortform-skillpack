# Writing the Comedy Movie — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- Not for drama
- Not for stand-up

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. Comedy is a skeleton of beats that support jokes
2. Joke-driven structure uses comic escalation instead of plot causality
3. Genre formulas are predictable comic patterns
4. The comic engine is a character trait applied consistently
5. Escalation beats are predictable variations on a comic rule

# Comedy Skeleton (Blake)

## R — Reading
Blake's skeleton: comedy is a skeleton of beats that support jokes. Unlike dramatic structure (causality), comic structure is about *variation* — each beat is a predictable variation on a comic rule, escalating until the payoff.

## I — Interpretation
The skeleton works because it separates the *structure* (what happens) from the *comedy* (what's funny). Same event beats can carry different comic payloads. The skeleton is the delivery mechanism — it determines when the joke lands.

## A1 — Application
For shortform: identify the comic rule, then design the skeleton to deliver it. Each beat should escalate the rule, not introduce new information.

## A2 — Trigger signals
- "Structure this comedy" - "This comedy has no spine" - "How do I make this escalate?"

## E — Executable steps
1. Write the comic rule (one falsifiable sentence).
2. Design 5-8 beats, each a variation on the rule.
3. Order beats from least to most extreme.
4. Position the payoff at the last beat.
5. Check: each beat must be a variation, not a new idea.

## B — Boundary / common failures
- **Trap**: beats that aren't variations — new information instead of rule variations.
- **Trap**: escalation that goes in circles — each beat must be *more* extreme.
- **Trap**: skeleton without a rule — random beats linked by theme.

﻿# Sitcom Ensemble

## R — Reading
Ensemble comedy distributes the comic engine across multiple perspectives. Each character has a different comic filter on the same situation. The ensemble works when perspectives are complementary, not redundant.

## I — Interpretation
The ensemble works because each character sees a different absurdity in the same event. The ensemble fails when characters are interchangeable (same comic filter) or when no anchor exists (everyone is absurd; no baseline for the audience).

## A1 — Application
For shortform: give each character a unique comic filter. The situation must serve all filters simultaneously.

## A2 — Trigger signals
- "Design a comedy ensemble" - "Three characters but only one is funny" - "Ensemble feels chaotic"

## E — Executable steps
1. Write the situation in one sentence.
2. For each character, write their unique filter on that situation.
3. Check: are filters complementary or redundant?
4. Identify the anchor (who is the audience's surrogate?).
5. Write beats where each filter produces a different reaction.

## B — Boundary / common failures
- **Trap**: filters that collide only occasionally — the ensemble needs constant perspective interference.
- **Trap**: no anchor — audience has no baseline for "normal."
- **Trap**: one character is the "real" comic; ensemble means every character generates comedy.

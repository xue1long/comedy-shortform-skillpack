﻿# Comic Premise — setup/twist/snapper

## R — Reading
The Comic Premise is the gap between comic reality and real reality. It is a falsifiable one-sentence assertion ("X is Y") that captures what the work satirizes. Structure: **Setup** (ordinary world) + **Twist** (gap revealed) + **Snapper** (premise paid off).

## I — Interpretation
Premise is not "theme" or "logline"; it is the atomic unit of comic intent. A premise that cannot be restated as a falsifiable gap cannot be tested. The premise determines whether the work is comedy or drama — a drama premise is "what happens"; a comic premise is "what the audience believes vs. what happens."

## A1 — Application
Use for any comic beat / sketch / story / scene where you need to know "what is this actually about?" Use it to detect when a sketch premise is too weak ("the gap is already in the setup") or too strong ("the gap is unresolvable").

## A2 — Trigger signals
- "What is this sketch actually about?"
- "Is this premise strong enough to carry a 60-second video?"
- "Why is this joke not landing?" (usually: the gap isn't falsifiable)
- Anytime the output is a premise statement.

## E — Executable steps
1. Name the *comic reality*: what absurd rule does the character/system follow?
2. Name the *real reality*: what would an ordinary audience expect instead?
3. Frame as one falsifiable sentence: "In this world, <gap>."
4. Decompose into Setup (establish the gap) / Twist (widen the gap) / Snapper (close it).
5. Sanity check: can a reader infer the snapper from the setup? If not, the gap is unclear.

## B — Boundary / common failures
- **Trap**: confusing premise with situation ("two people arguing" is a situation, not a premise).
- **Trap**: premise too broad ("life is hard" — no gap, no snapper).
- **Trap**: premise too narrow ("this coffee is hot" — no setup to escalate).
- **Not** a substitute for plot; premise is the assertion the plot tests.

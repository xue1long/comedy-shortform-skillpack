# Sitcom Arc — Old Stability / Instability / New Stability

## R — Reading
Sitcom structure is a closed-world ensemble form built on stability cycles:
- **Old Stability** — the world is in a stable state before the comic premise arrives
- **Instability** — the premise disrupts the world; the characters' conflicting perspectives generate the middle beats
- **New Stability** — the world settles into a new (often similar) stable state

Sub-structure: **A-story** carries the theme; **B-story** amplifies or contrasts it; story logic and plot logic must both be satisfied; a spec outline is mandatory.

## I — Interpretation
The three-phase model means the sitcom's job is to disrupt and re-stabilize — the comic premise is the disruptor. The characters are the world's stable elements; the episode's job is to break them briefly and reset them.

## A1 — Application
Use for sitcom-style ensemble comedy, dual-protagonist shorts with a "world" to disrupt, or any sketch that needs a "return to status quo" ending.

## A2 — Trigger signals
- "Structure this sitcom episode / dual-protagonist piece"
- "How do I make this feel like a complete sitcom arc?"
- "The characters are funny but the story doesn't go anywhere"
- "How do I write a spec sitcom outline?"

## E — Executable steps
1. Define Old Stability — the status quo before the premise.
2. State the premise (from comic-premise) — the force of disruption.
3. Map the instability beats (conflict between character perspectives).
4. Choose the New Stability — usually a minor variation on the Old.
5. Check A/B story alignment — A carries the premise; B amplifies or contrasts.

## B — Boundary / common failures
- **Trap**: New Stability that's identical to Old — the characters must have learned something, even if the world hasn't changed.
- **Trap**: B-story that contradicts the A-story premise — it must amplify, not undercut.
- **Trap**: outline-free writing — sitcoms are structurally rigid and need the outline.
- **Not** for one-joke sketches; use sketch-structure for single-rule forms.

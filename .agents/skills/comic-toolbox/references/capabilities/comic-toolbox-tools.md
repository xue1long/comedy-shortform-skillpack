# The Comic Toolbox (10 named tools)

## R — Reading
Vorhaus's toolbox is the set of atomic operations that generate comic surprise. Each tool produces a distinct mode of humor:
- **Clash of Context** — put two incompatible frames in the same scene
- **Wildly Inappropriate Response** — character reacts at wrong scale to stimulus
- **Law of Comic Opposites** — if A is true, the joke is "not-A" pushed to absurdity
- **Tension and Release** — build pressure, then break at the least expected moment
- **Position the Payoff** — put the comic payoff at the end of the sentence/scene
- **Truth/Lie to Comic Effect** — amplify or diminish a real signal to comic scale
- **Rule of Three** — two setups, one payoff; setup, setup, break
- **Jokoid** — a fake-out line that implies a joke is coming but delivers nothing
- **Doorbell Effect** — interruption defeats expectation at the worst moment
- **Running Gag / Callback** — repeat a motif with variation; close the loop at the end

## I — Interpretation
These are **generator** tools (apply them to a scene to produce a comic beat), not **evaluation** tools (they don't tell you if something is funny — Truth-and-Pain does that). The best comic work stacks 2–3 tools per beat.

## A1 — Application
- Use to generate a fresh comic beat from a dry premise.
- Use to diagnose "this scene is flat" — pick the missing tool.
- Use to escalate a beat — choose the next tool in the escalation chain.
- Stack with premise/funnel — the tools are how you *fulfill* the premise.

## A2 — Trigger signals
- "Give me a funnier version of this scene"
- "This joke doesn't land — what's missing?"
- "Which tool do I use to make this more surprising?"
- "How do I escalate this bit?"

## E — Executable steps
1. Identify the scene's current tool or state (setup only, no release, etc.).
2. Pick the *next* tool in the chain (clash → response → tension → release).
3. Apply the rule mechanically: e.g., "Rule of Three" → write two straight setups, then a twist.
4. Verify the snapper lands at the end (positioning payoff).
5. If the result is flat, add Jeopardy or raise the exaggeration.

## B — Boundary / common failures
- **Trap**: using all tools at once produces noise — pick one dominant tool per beat.
- **Trap**: Rule of Three with no variation — the third beat must genuinely break the pattern.
- **Trap**: Wildly Inappropriate Response without perspective — it reads as random, not comic.
- **Not** for emotional or dramatic scenes; the toolbox is for comic beats only.

# 决策规则速查 — Writing Dialogue

| 能力 | 一句话规则 |
|---|---|
| Dialogue Listening (Jot + Crowd) | Collect raw speech via jotting and crowding. |
| Dialogue Misdirection | Make the audience look one way while truth walks by the other. |
| Dialogue Compression | Strip dialogue to barest bones; write fat, then cut. |
| Dialogue Tension (Direction + Speed + Distance) | Direction, speed, and distance create dialogue tension. |
| Silence as Dialogue | Sometimes shut up; let silence answer. |
| Dialect & Diction Control | Word choice before accent; trust the language. |
| Dialogue Tags & Punctuation | Never use adverbs in tags; said is invisible. |
| Gesture in Dialogue | Fill silence with dramatic, particular, incidental gesture. |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

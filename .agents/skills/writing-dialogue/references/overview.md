# Writing Dialogue — Book Overview

- **Title**: Writing Dialogue
- **Author**: Tom Chiarella
- **Year**: 1998
- **Structure**: 8 chapters covering listening, tension, dialect, compression, silence, dialogue triggers, technical craft, appendix.
- **Central claim**: Dialogue is an event, not information transfer. Good dialogue must be heard before it can be written.
- **Key terms**: jotting, crowding, direction/speed/distance, directed/interpolated/misdirected/modulated, compression, gesture

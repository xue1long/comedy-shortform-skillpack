# Dialogue Tension — Direction + Speed + Distance
## R — Reading
Good dialogue has **direction** (each character wants something specific), **speed** (lines move at a rate the audience must chase), **distance** (the gap between what characters say and what they mean). Highway model: two cars at the same speed, same direction — no tension. Change any one variable and tension appears. Also: four dialogue types — directed, interpolated, misdirected, modulated — each manipulates the three levers differently.
## I — Interpretation
Tension is the engine that keeps dialogue from becoming ping-pong exposition. Direction gives each line an owner and a goal; speed sets the tempo; distance creates subtext. A scene with zero distance (everyone says what they mean) reads as a memo.
## A1 — Application
For comedy: comic tension often = small direction + exaggerated speed (trivial want pursued at breakneck pace) or large distance (polite words, furious intent). Choose which lever carries the joke.
## A2 — Trigger signals
- "This scene is flat / boring"
- "The characters talk but nothing happens"
- "Where's the tension in this exchange?"
## E — Executable steps
1. Write each character's want in one sentence — if identical or unclear, fix direction first.
2. Set the speed: count line lengths; monologue blocks kill speed.
3. Increase distance: rewrite one line so the speaker means the opposite of what they say.
4. Check the highway: if both characters move the same direction/speed, change a variable.
5. Classify the dialogue type; misdirected dialogue needs a live question first.
## B — Boundary / common failures
- **Trap**: speed mistaken for shouting — tempo is structural, not volume.
- **Trap**: distance without anchor — the audience needs to sense the true meaning.
- **Trap**: direction = plot goal; dialogue direction is the *line-level* want (to win this reply).

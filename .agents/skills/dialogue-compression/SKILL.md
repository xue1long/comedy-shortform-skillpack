﻿# Dialogue Compression
## R — Reading
To defeat bloated dialogue: write it all, then compress. Watchwords: **Figure it out / Cut it out / Read it out / Turn it out**. The five-word rule: most lines should compress toward five words or fewer. Compression/release cycle: tighten until it hurts, then release one beat for rhythm. Chiarella's bloat-strategy: overwrite deliberately, then cut in passes — never try to write lean in the first draft.
## I — Interpretation
Compression works because spoken dialogue is already elliptical — the audience fills gaps faster than actors can speak them. Every explained line is a doubled line: the audience gets it twice. Cutting removes the second telling.
## A1 — Application
For shortform: dialogue budget ≈ 25–40 lines in 60s. First pass: write everything the scene wants to say (~60 lines). Second pass: five-word rule per line. Third pass: cut any line whose information exists elsewhere.
## A2 — Trigger signals
- "This scene runs long"
- "Cut this dialogue down"
- "The lines feel heavy / explanatory"
## E — Executable steps
1. Write the scene fat — every thought spoken.
2. Pass 1 — Cut answers that are obvious from context.
3. Pass 2 — Five-word rule: rewrite each line to ≤5 words unless rhythm demands longer.
4. Pass 3 — Read aloud; mark any line you stumble on, cut or reword.
5. Release check: add back exactly one breath line where compression chokes flow.
## B — Boundary / common failures
- **Trap**: compressing in the first draft — you can't cut what isn't there.
- **Trap**: five-word rule applied uniformly — rhythm needs variation.
- **Trap**: cutting the setup lines; bloat usually hides in answers, not setups.

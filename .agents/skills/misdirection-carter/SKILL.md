﻿# Misdirection (Carter)

## R — Reading
Misdirection makes the audience look one way while truth walks by another. Carter's model: the setup must be fair — the audience must be able to see the misdirection in retrospect. The misdirection works because the audience is actively predicting.

## I — Interpretation
Misdirection works because the audience is actively predicting — they see the setup and predict the punchline. The misdirection fails when the setup is too obvious (the audience sees the misdirection coming) or when the punchline is too obscure (the audience doesn't catch it).

## A1 — Application
For shortform: place the misdirection in the setup — the audience predicts one thing, the punchline delivers another.

## A2 — Trigger signals
- "Apply misdirection" - "Make this surprising" - "Hide the punchline"

## E — Executable steps
1. Write the setup — clear, specific, creates an expectation.
2. Write the misdirection — the audience predicts one thing.
3. Write the punchline — delivers something else.
4. Check: is the setup fair — can the audience see the misdirection in retrospect?
5. Check: is the punchline surprising — does it break the expectation?
6. Verify: the misdirection should feel earned, not forced.

## B — Boundary / common failures
- **Trap**: setup too obvious — the audience sees the misdirection coming.
- **Trap**: punchline too obscure — the audience doesn't catch it.
- **Trap**: misdirection that's just a lie — the setup must be fair.

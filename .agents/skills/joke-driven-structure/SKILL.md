﻿# Joke-Driven Structure
## R — Reading
Joke-driven structure is the alternative to character-driven plotting. Instead of "what does the character want next," the engine is "what comic rule gets escalated next." Vorhaus distinguishes this from sitcom (character-driven) — joke-driven works for sketch, film parody, gag-based comedy where the premise is already funny.
## I — Interpretation
Joke-driven works because the audience is tracking the comic rule, not the character arc. Each joke tests or extends the rule. The structure is a chain of gags linked by a single escalating rule rather than a chain of plot events.
## A1 — Application
For shortform where the premise is already comic ("what if X"): the joke-driven skeleton is establish-rule → escalate×3 → break. Each escalation is a *variation* on the rule (a different way the absurdity plays out).
## A2 — Trigger signals
- "Structure this sketch"
- "The premise is funny but the scene is flat"
- "How do I make this gag-based?"
## E — Executable steps
1. Write the comic rule.
2. List 3-5 ways the rule can escalate (different contexts, characters, degrees).
3. Order them from least to most extreme.
4. The payoff is the escalation that breaks the pattern — the rule applied to itself or pushed to impossibility.
5. Cut anything that isn't a variation on the rule.
## B — Boundary / common failures
- **Trap**: escalation without variation — same joke louder is not escalation.
- **Trap**: joke-driven without a rule — random gags linked by theme.
- **Not** for sitcom/character-driven where the character's need drives the comedy.

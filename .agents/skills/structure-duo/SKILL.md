# 双主角结构

## 目标
让两人选择相互改变局面，而非轮流说笑话。

## 输入
两人的眼前目标、不可让步之处、误解或信息差、首次权力分布、场景限制与时长。确认谁能做出行动，以及谁需要对方配合。

## 适用条件
两个可见行动者共同推动场面；可与 Sketch 叠加。用户只需要可重复规则的节拍时用 `structure-sketch`；完整剧本使用 `comedy-shortform-writer`。

## 步骤
1. 分别写明两人的眼前目标及不可让步之处，避免把人物简化成“说笑话的人”和“接话的人”。
2. 找出双方各自掌握的信息、资源或地位与第一次权力落点。
3. 用一方行动迫使对方改变策略，再让对方反制并改变局面；每次攻防都应有可见后果。
4. 让结尾兑现两人关系、信息差或相互依赖，不新增第三人替他们解决。

## 判断与停止
若删掉任一角色后场面仍不变，说明尚不是双主角结构；先设计一方的行动如何改变另一方选择。若关键目标未知，提出一个澄清问题再继续。

## 输出
双方目标与不可让步处、信息差、初始权力、攻防节拍、权力变化、结尾兑现和时长／拍摄限制。

## 边界与失败
双主角不等于必须平均分配台词；不与 Sketch 互斥。若一人始终不影响另一人的决定，指出关系结构尚未成立。

## 示例
顾客索回时间，员工按分钟退款；顾客证明等待更久，反使自己欠柜台服务费。顾客改变员工的结算方式，员工的反制又改变顾客的目标。

## 相关技能
完整短剧本使用 `comedy-shortform-writer`；重复规则可用 `structure-sketch`。本 Skill 可独立调用。

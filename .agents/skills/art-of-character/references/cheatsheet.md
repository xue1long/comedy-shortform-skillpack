# 决策规则速查 — The Art of Character

| 能力 | 一句话规则 |
|---|---|
| Character Desire Engine | Character desire = want vs need; the gap is the drama. |
| Character Contradiction | Contradiction is the engine of depth: a character who contains opposites. |
| Character Ghost / Backstory | A ghost is a past wound that shapes present desire. |
| Character Transformation | Transformation: growth through action, not realization. |
| Scene-Based Character Revelation | Reveal character through action under pressure, not description. |
| Character Voice & POV | Voice triad: diction, rhythm, attitude. |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

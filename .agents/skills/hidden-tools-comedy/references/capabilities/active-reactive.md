# Active vs Reactive Emotion
## R — Reading
Active emotion drives comedy; reactive emotion kills it. Active emotion = the hero wants something NOW and pursues it. Reactive emotion = the hero responds to what's happening. Kaplan's rule: the hero must act, not just react — the comedy comes from their attempt to impose their will on a world that disagrees.
## I — Interpretation
Active emotion works because it gives the hero agency — they cause events rather than suffering them. Reactive emotion produces victims, not heroes. The audience laughs at the hero's attempt, not at their suffering.
## A1 — Application
For shortform: rewrite any beat where the hero is only reacting. Give them an action — even if it's wrong, even if it fails. The comedy is in the attempt.
## A2 — Trigger signals
- "The hero feels passive"
- "Why isn't this funny?"
- "Make this character more active"
## E — Executable steps
1. Identify the hero's current action (or lack thereof).
2. If reactive (responding to events), give them an action that CAUSES the event.
3. Check: does the hero's action make things worse? (Good — that's comedy.)
4. Check: does the hero have a want NOW (not a memory or a wish)?
5. Rewrite beats where the hero waits for the plot to happen.
## B — Boundary / common failures
- **Trap**: hero who's a victim — they must cause their own problems.
- **Trap**: action without want — the hero must want something, not just do something.
- **Trap**: emotion without action — feeling isn't doing.

# 决策规则速查 — The Hidden Tools of Comedy

| 能力 | 一句话规则 |
|---|---|
| The Comic Equation | Comedy = ordinary person + insurmountable odds + insufficient skills + no hope of success. |
| Comic Hero Design | Comic hero: winning, positive action, active emotion — not trying to be funny. |
| Positive / Negative Push | Positive push = what hero pursues; negative push = what the world pushes back. |
| Straight Line / Wavy Line | Straight line = focus/anchor; wavy line = comic disturbance. |
| Active vs Reactive Emotion | Active emotion drives comedy; reactive emotion kills it. |
| Comic Premise (Kaplan) — closed-universe operating rule | One lie the closed universe operates on; combine with comic equation (truth × pain × distance). |
| Joke Tests | A joke must pass 4 tests: surprise, specificity, compression, variety. |
| Comic Polyphony | Polyphony = multiple comic voices that dont cancel each other. |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

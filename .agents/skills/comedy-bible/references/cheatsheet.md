# 决策规则速查 — The NEW Comedy Bible

| 能力 | 一句话规则 |
|---|---|
| Joke Structure | Setup creates expectation; punchline breaks it. |
| Comic Premise (Carter) — the world's lie, falsifiable | One lie the world believes — falsifiable, world-level (not character-level). |
| Setup / Punchline (one-line mechanic) | Setup creates expectation; punchline breaks it with surprise. |
| Callback | Callback repeats a motif with variation; closes the loop. |
| Rule of Three | Two setups, one break; setup, setup, surprise. |
| Misdirection (Carter) | Misdirection makes the audience look one way while truth walks by another. |
| Comic Escalation (Carter) | Escalation is predictable variation on a comic rule. |
| Comic Character (Carter) | Comic character = exaggerated trait applied consistently. |

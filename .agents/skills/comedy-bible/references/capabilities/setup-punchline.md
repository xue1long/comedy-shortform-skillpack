# Setup / Punchline (one-line mechanic)

## R — Reading
Carter's most atomic joke application: a single beat consisting of one setup
+ one punchline. The setup is the trap — the audience forms a specific
prediction from one piece of information. The punchline is the release —
that prediction is violated in a single line. The setup must be specific
enough to be releasable; the punchline must land in a single beat, not a
multi-line cascade.

## I — Interpretation
Setup/punchline works because it minimizes the audience's working memory
— they only need to hold one expectation before the punchline lands. It's
the purest version of joke-structure: any single setup/punchline pair is
also a valid joke-structure, but joke-structure can also describe longer
cascades (set-up → misdirect → reveal). When you want the tightest
possible comic moment, use this — when you want the most flexible, use
joke-structure.

## A1 — Application
For shortform: a single setup/punchline is the smallest possible comic
beat. Use it for one-liners, opening gags, snapper lines, and any moment
where you have one beat and one chance. Use joke-structure for multi-line
or multi-scene joke construction.

## A2 — Trigger signals
- "Write a one-liner"
- "I need a single beat"
- "Just one joke for the snapper"
- "The smallest possible comic moment"

## E — Executable steps
1. Write the setup as a single sentence (or half-sentence).
2. State the expectation it creates in one phrase.
3. Write the punchline as a single sentence that breaks that exact expectation.
4. Check: is the punchline one beat (not a cascade)?
5. Use this skill when one beat is enough; use joke-structure when you need multiple.

## B — Boundary / common failures
- **Trap**: setup that's too vague — no releasable expectation in one beat.
- **Trap**: punchline that's a cascade — use joke-structure instead.
- **Trap**: setup and punchline that don't connect — the break must hit the setup's expectation.
- **Distinguish from joke-structure**: setup/punchline is the one-beat
  atomic application; joke-structure can also describe multi-line cascades.

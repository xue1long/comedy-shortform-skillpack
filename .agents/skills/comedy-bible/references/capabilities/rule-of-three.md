# Rule of Three

## R — Reading
Two setups, one break; setup, setup, surprise. Carter's model: the third element breaks the pattern established by the first two. The rule works because the audience is trained to expect patterns — two is a pattern, three is a surprise.

## I — Interpretation
The rule works because the audience is actively predicting — the first two elements create a pattern, the third breaks it. The rule fails when the first two elements don't create a clear pattern, or when the third element doesn't break it.

## A1 — Application
For shortform: use the rule of three for escalation. The first two beats establish the pattern; the third breaks it.

## A2 — Trigger signals
- "Write a rule of three" - "Escalate this bit" - "Make this funnier"

## E — Executable steps
1. Write the first setup — clear, specific.
2. Write the second setup — similar to the first.
3. Write the break — unexpected, breaks the pattern.
4. Check: do the first two elements create a clear pattern?
5. Check: does the third element break the pattern?
6. Verify: the break should feel inevitable in retrospect.

## B — Boundary / common failures
- **Trap**: first two elements don't create a clear pattern.
- **Trap**: third element doesn't break the pattern.
- **Trap**: break that's too predictable — no surprise.

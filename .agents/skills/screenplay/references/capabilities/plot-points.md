# Plot Points

## R — Reading
Field defines Plot Point as "any incident, episode, or event that hooks into the action and spins it around in another direction." Plot Point I moves the action into Act II; Plot Point II moves it into Act III. They are the structural hinges — the moments where the story's direction changes irreversibly.

## I — Interpretation
Plot points are *direction changers*, not just climaxes or turning points. A climax resolves conflict; a plot point redirects it. The distinction: a plot point changes *what* the protagonist must do, not just *how hard* it is.

## A1 — Application
For shortform: the key plot point is the moment where the comic rule breaks — the audience expects one thing, gets another. In a 60s piece, this is usually the payoff moment (the snapper). Place it at 80–90% of runtime.

## A2 — Trigger signals
- "Where's the plot point?"
- "This story needs a turn"
- "How do I make this story pivot?"

## E — Executable steps
1. Identify the story's current direction.
2. Write the event that would reverse or redirect that direction.
3. Check: does the event change *what* must happen next, not just *how* it happens?
4. Place the plot point at the act boundary (or the comic break).
5. Verify the story can't continue in the old direction after the plot point.

## B — Boundary / common failures
- **Trap**: plot point that's just a climax — it must change direction.
- **Trap**: plot point that's too early — the story hasn't built enough momentum.
- **Trap**: plot point that doesn't stick — the story tries to continue as if it didn't happen.

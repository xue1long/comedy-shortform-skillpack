# 决策规则速查 — Screenplay

| 能力 | 一句话规则 |
|---|---|
| Scene Design | A scene is a unit of action with a want and an obstacle. |
| Three-Act Structure | Setup, confrontation, resolution; inciting incident and climax as hinges. |
| Conflict Chain | Each scene produces a new conflict that drives the next. |
| Plot Points | Plot points are the moments that change the direction of the story. |
| Character-Plot Integration | Character and plot are two sides of the same coin. |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

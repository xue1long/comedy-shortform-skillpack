﻿# Joke Structure

## R — Reading
Carter's atomic joke: setup creates expectation; punchline breaks it. The setup is the trap — the audience forms a prediction. The punchline is the release — the prediction is violated. Two-sided test: setup clear enough to create expectation; punchline unexpected enough to surprise.

## I — Interpretation
The joke works because the audience is an active predictor. The setup must give them a specific direction to predict; the punchline must break it. If the setup is too vague, the audience has no expectation to break. If the punchline is too predictable, there's no surprise. The setup and punchline must be connected — the break must be on the setup's expectation, not a random twist.

## A1 — Application
For shortform: every comic beat needs a clear setup + unexpected punchline. The setup is the "normal" version; the punchline is the comic twist.

## A2 — Trigger signals
- "Write a joke" - "Make this funny" - "What's the setup/punchline?"

## E — Executable steps
1. Write the setup — clear, specific, creates an expectation.
2. Write the punchline — unexpected, breaks the expectation.
3. Check: is the setup clear enough to create a specific expectation?
4. Check: is the punchline unexpected enough to surprise?
5. Verify: the punchline should feel inevitable in retrospect.

## B — Boundary / common failures
- **Trap**: setup too vague — no expectation to break.
- **Trap**: punchline too predictable — no surprise.
- **Trap**: setup and punchline don't connect — the break must be on the setup's expectation.
